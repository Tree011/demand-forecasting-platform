# ForecastIQ

AI-powered forecasting platform capable of forecasting any business metric from historical time-series data.

## Features

- CSV Upload
- Automated Feature Engineering
- XGBoost Forecasting
- Interactive Visualizations
- Forecast Download
- Streamlit Dashboard

## Tech Stack

- Python
- Pandas
- XGBoost
- Streamlit
- Plotly
